# The Three Little Cats and the Hungry Dog

This folder is ready for GitHub Pages.

Files:
- `index.html`, the webpage
- `assets/`, optimized WebP images
- `.nojekyll`, disables Jekyll processing for a plain static site

GitHub Pages setup:
1. Upload `index.html`, `.nojekyll`, and the `assets` folder to your repository.
2. Go to Settings > Pages.
3. Set Source to Deploy from a branch.
4. Choose `main` branch and root folder `/`.
5. Save and wait for Pages to publish.
