Framework

Six Principles Behind Every Episode

Each session is built on six interdependent principles. Remove any one and the diagnostic precision breaks down.

01
Grammar in Context
Grammar is never taught in isolation. Every structure is embedded in a real narrative scenario that requires active production, not explanation.
02
Timed Output
Response latency is measured every session. Hesitation over 2 seconds on a target structure flags it for the next episode. The data, not intuition, drives the next step.
03
Episode Architecture
Each session is a self-contained story with a dramatic arc. Comprehension, analysis, and production flow in a fixed sequence. The student always knows where they are.
04
Real-time Diagnostics
The teacher dashboard captures every response live. Tense switches, latency, and confidence are logged before the session ends, never reconstructed from memory.
05
Spaced Repetition
High-frequency vocabulary and target structures recur across episodes with increasing complexity and reduced scaffolding. Retention is built through return, not drilling.
06
Student-built Content
Every episode is written around the individual student's documented gaps, interests, and cultural context. Generic content doesn't produce diagnostic-grade data.
Session Structure

Three Blocks. Every Session.

The structure never changes. The content changes every time. The student knows the pattern; the pressure comes from the material.

01
Listen
Immersive story input. Illustrated scene stage, sentence-by-sentence caption, past-tense vocabulary in context. The student receives before they produce.
→
02
Analyse
Grammar target identification. Timed branch choices and sentence frame completion. Every verb switch is measured. The teacher dashboard logs in real time.
→
03
Produce
Free output under a two-minute deadline. No options, no frames. The student writes their own conclusion. This is the diagnostic output for the next episode.
