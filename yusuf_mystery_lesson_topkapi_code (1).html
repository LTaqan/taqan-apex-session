Scene 3 — The Locked Room
Room 14B. The door is locked with a digital keypad.
Beside it, a screen shows a Python list of suspects — but one has already been cleared by security cameras.

"We need to remove the cleared suspect from the list," Selin says. "Otherwise the lock won't accept the code. The cleared suspect is at index 1."

You remember from your Python sessions: .pop() removes an item by index.
The Suspect List
suspects = ["Ali", "Burcu", "Mert"] # Burcu is at index 1 — cameras show she is innocent # Remove her from the list suspects.pop(1) print(suspects)
Python Challenge 2 of 3
